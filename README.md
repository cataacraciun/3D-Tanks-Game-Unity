# 3D Tanks Game - Unity

A 3D tank battle game built in Unity. Includes AI enemies, power-ups, health kits, guided missiles, and a capture-the-flag game mode.

## 🎮 Features

- 🧠 AI-controlled enemy tanks
- 🛡️ Temporary shield power-ups
- 💣 Guided missiles, minigun, and artillery weapons
- 💊 Repair kits (health pickups)
- 🏁 Capture the flag mode
- ⚙️ Realistic tank physics and sound

## 🛠️ Technologies Used

- Unity (3D Engine)
- C#
- Git & GitHub

## 🚀 How to Run

1. Clone the repository:
git clone https://github.com/cataacraciun/3D-Tanks-Game-Unity.git
2. Open the project in Unity Hub
3. Select the `Scenes/MainScene.unity` (or your main scene)
4. Press `Play`
